# Swift Binding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Status (2026-10-15):** Superseded. This plan was executed on the orphaned `design/swift-binding` branch; `2026-08-23-swift-binding-port.md` carried that work onto the published lineage. Its checkboxes are left as they were.

**Goal:** Ship a reusable, published Swift package that exposes the Chisel storage engine to iOS and macOS apps through an idiomatic sync + async API, bridged from Rust via UniFFI.

**Architecture:** A new `chisel-ffi` Rust crate wraps `chisel::Chisel` in `Mutex<Option<Chisel>>` and exports flat, synchronous methods with `#[uniffi::export]`. UniFFI generates a C-ABI static library plus idiomatic Swift. A `swift/` SPM package ships that library as a prebuilt `.xcframework` and layers hand-written ergonomics on top: a synchronous `ChiselDatabase`, an `async` `ChiselStore` actor backed by a dedicated serial queue, and transaction/savepoint closures. The engine crate is never modified.

**Tech Stack:** Rust (edition 2021, MSRV 1.82), `uniffi` (proc-macro / library mode), `zeroize`; Swift 6, Swift Package Manager, `.xcframework`, XCTest, `xcodebuild -create-xcframework`, GitHub Actions (macOS runner).

**Reference spec:** `docs/specs/2026-07-18-swift-binding-design.md`.

## Global Constraints

- **No engine edits.** `src/**` (the `chisel` crate) is consumed unmodified. All new Rust lives in `chisel-ffi/`.
- **MSRV 1.82**, edition 2021 — mirror the root crate exactly (`chisel-ffi/Cargo.toml`).
- **Workspace wiring:** add `chisel-ffi` to `[workspace] members` but NOT to `default-members`, exactly like `python` (so `cargo build`/`test` from the root are unaffected).
- **`chisel-ffi` crate-types:** `["staticlib", "cdylib", "lib"]`.
- **UniFFI library mode + proc-macros only** (no UDL). Call `uniffi::setup_scaffolding!()` once.
- **Single-thread invariant** is enforced by the `Mutex` in the FFI crate; the engine stays `!Sync`. Never expose a path that touches the engine without holding the lock.
- **`usize` never crosses the FFI** — use `u64` at the boundary and convert inside.
- **Minimum deployment target:** iOS 15 / macOS 12.
- **No Claude/AI-referencing text** in commit messages, code comments, or docs (project rule).
- **Commit style:** conventional commits (`feat:`, `test:`, `docs:`, `chore:`), present tense.
- The xcframework is **`.gitignore`'d**, never committed.
- Public Swift API names are the product surface; the UniFFI-generated low-level object is named `NativeDatabase` and is documented "internal — prefer `ChiselStore`/`ChiselDatabase`."

```rust
// chisel-ffi — UniFFI binding surface for the Chisel engine.
//
// Role in system: the ONLY crate that speaks the C ABI. It wraps chisel::Chisel
// in a Mutex (the engine is Send + !Sync) and re-presents a flat, synchronous
// API to UniFFI, which generates Swift. All ergonomics (async actor, closures)
// live in the Swift package, not here.

uniffi::setup_scaffolding!();

// Compile-time proof that the engine can move between threads, which the
// Mutex<Option<Chisel>> wrapper in database.rs relies on. If a future engine
// change (mmap, raw OS handle) makes Chisel !Send, THIS line fails to compile
// with a clear message, and the fallback is a dedicated-thread actor (see spec
// §3.3). Cheap insurance against a wrong assumption.
const _: () = {
    fn assert_send<T: Send>() {}
    let _ = assert_send::<chisel::Chisel>;
};

/// Returns the crate version, e.g. "0.1.0". Smoke test that the whole
/// Rust→UniFFI→Swift pipeline is wired end to end.
#[uniffi::export]
pub fn library_version() -> String {
    env!("CARGO_PKG_VERSION").to_string()
}
```

```bash
#!/usr/bin/env bash
# Builds Chisel.xcframework from the chisel-ffi crate and regenerates the
# Swift bindings. Run from the repo root: swift/build-xcframework.sh
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
OUT="$ROOT/swift"
BUILD="$OUT/.xcbuild"
GEN="$OUT/Sources/Chisel/Generated"
LIBNAME="libchisel_ffi.a"

TARGETS=(
  aarch64-apple-ios
  aarch64-apple-ios-sim
  x86_64-apple-ios
  aarch64-apple-darwin
  x86_64-apple-darwin
)
for t in "${TARGETS[@]}"; do rustup target add "$t" >/dev/null; done

echo "==> cargo build (release) for all Apple targets"
for t in "${TARGETS[@]}"; do
  cargo build -p chisel-ffi --release --target "$t"
done

rm -rf "$BUILD" && mkdir -p "$BUILD"

# Fat libs: one per platform group.
lipo -create \
  "$ROOT/target/aarch64-apple-ios-sim/release/$LIBNAME" \
  "$ROOT/target/x86_64-apple-ios/release/$LIBNAME" \
  -output "$BUILD/libchisel_ffi-ios-sim.a"
lipo -create \
  "$ROOT/target/aarch64-apple-darwin/release/$LIBNAME" \
  "$ROOT/target/x86_64-apple-darwin/release/$LIBNAME" \
  -output "$BUILD/libchisel_ffi-macos.a"
cp "$ROOT/target/aarch64-apple-ios/release/$LIBNAME" "$BUILD/libchisel_ffi-ios.a"

echo "==> generate Swift bindings"
rm -rf "$GEN" && mkdir -p "$GEN"
cargo run -p chisel-ffi --bin uniffi-bindgen -- generate \
  --library "$ROOT/target/aarch64-apple-darwin/release/$LIBNAME" \
  --language swift --out-dir "$GEN"

# UniFFI emits chisel.swift + chiselFFI.h + chiselFFI.modulemap.
# Headers go into the xcframework; the .swift stays in the target.
HEADERS="$BUILD/headers"
mkdir -p "$HEADERS"
mv "$GEN/chiselFFI.h" "$HEADERS/"
mv "$GEN/chiselFFI.modulemap" "$HEADERS/module.modulemap"

echo "==> create Chisel.xcframework"
rm -rf "$OUT/Chisel.xcframework"
xcodebuild -create-xcframework \
  -library "$BUILD/libchisel_ffi-ios.a"     -headers "$HEADERS" \
  -library "$BUILD/libchisel_ffi-ios-sim.a" -headers "$HEADERS" \
  -library "$BUILD/libchisel_ffi-macos.a"   -headers "$HEADERS" \
  -output "$OUT/Chisel.xcframework"

echo "==> done: $OUT/Chisel.xcframework"
```

Make it executable: `chmod +x swift/build-xcframework.sh`.

```rust
//! FFI error surface. Flattens the engine's ChiselError into one UniFFI enum;
//! `.category`/`.isPoisoning` live on the Swift side (Extensions.swift).

/// Result alias for exported fallible methods.
pub type FfiResult<T> = Result<T, ChiselError>;

#[derive(Debug, uniffi::Error)]
pub enum ChiselError {
    // --- operational: database state intact ---
    InvalidHandle,
    NoActiveTransaction,
    TransactionAlreadyActive,
    SavepointNotFound { name: String },
    DuplicateSavepoint { name: String },
    ReadOnlyMode,
    DatabaseFileNotFound,
    InvalidRootName,
    RootNameTableFull,
    InvalidSuperblockCount,
    CacheFull,
    SpillwayFull,
    TransactionInProgress,
    Closed,
    AlreadyFinished,
    TagMismatch,
    NoEncryptionKey,
    InvalidEncryptionKey,
    EncryptionNotSupported,
    NoFreeKeySlot,
    LastKeySlot,
    // --- fatal: database poisoned / on-disk state suspect ---
    Io { kind: String, errno: Option<i32> },
    ChecksumMismatch,
    CorruptSuperblock,
    FileSizeMismatch,
    LockFailed,
    UnsupportedFormatVersion,
    UnsupportedPageSize,
    CorruptPage,
    InvalidPageId,
    Poisoned,
    DecryptionFailed,
}

impl std::fmt::Display for ChiselError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{self:?}")
    }
}
impl std::error::Error for ChiselError {}

impl From<chisel::ChiselError> for ChiselError {
    fn from(e: chisel::ChiselError) -> Self {
        use chisel::ChiselError as E;
        match e {
            E::InvalidHandle => Self::InvalidHandle,
            E::NoActiveTransaction => Self::NoActiveTransaction,
            E::TransactionAlreadyActive => Self::TransactionAlreadyActive,
            E::SavepointNotFound(name) => Self::SavepointNotFound { name },
            E::DuplicateSavepoint(name) => Self::DuplicateSavepoint { name },
            E::ReadOnlyMode => Self::ReadOnlyMode,
            E::DatabaseFileNotFound => Self::DatabaseFileNotFound,
            E::InvalidRootName => Self::InvalidRootName,
            E::RootNameTableFull => Self::RootNameTableFull,
            E::InvalidSuperblockCount => Self::InvalidSuperblockCount,
            E::CacheFull => Self::CacheFull,
            E::SpillwayFull => Self::SpillwayFull,
            E::TransactionInProgress => Self::TransactionInProgress,
            E::Closed => Self::Closed,
            E::AlreadyFinished => Self::AlreadyFinished,
            E::TagMismatch => Self::TagMismatch,
            E::NoEncryptionKey => Self::NoEncryptionKey,
            E::InvalidEncryptionKey => Self::InvalidEncryptionKey,
            E::EncryptionNotSupported => Self::EncryptionNotSupported,
            E::NoFreeKeySlot => Self::NoFreeKeySlot,
            E::LastKeySlot => Self::LastKeySlot,
            E::IoError(io) => Self::Io {
                kind: format!("{:?}", io.kind()),
                errno: io.raw_os_error(),
            },
            E::ChecksumMismatch => Self::ChecksumMismatch,
            E::CorruptSuperblock => Self::CorruptSuperblock,
            E::FileSizeMismatch => Self::FileSizeMismatch,
            E::LockFailed => Self::LockFailed,
            E::UnsupportedFormatVersion => Self::UnsupportedFormatVersion,
            E::UnsupportedPageSize => Self::UnsupportedPageSize,
            E::CorruptPage => Self::CorruptPage,
            E::InvalidPageId => Self::InvalidPageId,
            E::Poisoned => Self::Poisoned,
            E::DecryptionFailed => Self::DecryptionFailed,
        }
    }
}
```

```rust
//! FFI value types. Records/enums UniFFI passes by value, plus the custom_type!
//! bridges for the engine's Handle/Tag newtypes and the Options builder mapping.
use crate::error::ChiselError;

// Handle bridges as a plain u64 (engine has From<u64>/From<Handle> for u64).
uniffi::custom_type!(chisel::Handle, u64);

// Tag bridges as u32; try_lift rejects 0 (engine Tag is NonZeroU32 via
// TryFrom<u32> with ZeroTagError). The shorthand uses the engine's TryFrom.
uniffi::custom_type!(chisel::Tag, u32);

#[derive(uniffi::Enum, Clone, Copy, PartialEq, Eq, Debug)]
pub enum DrainInsertion { LruTail, Mru }

impl From<DrainInsertion> for chisel::DrainInsertion {
    fn from(d: DrainInsertion) -> Self {
        match d {
            DrainInsertion::LruTail => chisel::DrainInsertion::LruTail,
            DrainInsertion::Mru => chisel::DrainInsertion::Mru,
        }
    }
}
impl From<chisel::DrainInsertion> for DrainInsertion {
    fn from(d: chisel::DrainInsertion) -> Self {
        match d {
            chisel::DrainInsertion::LruTail => DrainInsertion::LruTail,
            chisel::DrainInsertion::Mru => DrainInsertion::Mru,
            _ => DrainInsertion::LruTail, // #[non_exhaustive] catch-all
        }
    }
}

#[derive(uniffi::Enum, Clone, Debug)]
pub enum ChiselKey {
    Raw { bytes: Vec<u8> },
    Passphrase { phrase: String },
}

impl ChiselKey {
    pub(crate) fn into_engine(self) -> chisel::crypto::Key {
        // NOTE: `chisel::crypto::Key` is pub(crate) in the engine's module tree
        // but re-exported? Confirm the public path. If `Key` is NOT public,
        // route through the Options.encryption_key setter and the add/rotate/
        // remove_key methods, which accept the engine Key by its public path.
        use zeroize::Zeroizing;
        match self {
            ChiselKey::Raw { bytes } => chisel::Key::Raw(Zeroizing::new(bytes)),
            ChiselKey::Passphrase { phrase } => {
                chisel::Key::Passphrase(Zeroizing::new(phrase))
            }
        }
    }
}
```

```rust
//! The exported UniFFI object. Holds the engine behind Mutex<Option<Chisel>>:
//! the Option lets `close(self)` consume the engine (UniFFI methods only get
//! &self behind an Arc), and a None inner yields Closed for any later call.
use std::sync::Mutex;
use crate::error::{ChiselError, FfiResult};
use crate::types::{Counters, DefragOptions, DefragStats, DrainInsertion, Options,
                   Stats, TagDropProgress};

#[derive(uniffi::Object)]
pub struct NativeDatabase {
    inner: Mutex<Option<chisel::Chisel>>,
}

impl NativeDatabase {
    /// Lock, reject if closed, run `f` with &mut engine. All &mut methods use this.
    fn with_db<R>(
        &self,
        f: impl FnOnce(&mut chisel::Chisel) -> Result<R, chisel::ChiselError>,
    ) -> FfiResult<R> {
        let mut guard = self.inner.lock().map_err(|_| ChiselError::Poisoned)?;
        let db = guard.as_mut().ok_or(ChiselError::Closed)?;
        f(db).map_err(Into::into)
    }
}

#[uniffi::export]
impl NativeDatabase {
    /// Open (or create) a file-backed database. `path == None` opens in-memory.
    #[uniffi::constructor]
    pub fn new(path: Option<String>, options: Options) -> FfiResult<std::sync::Arc<Self>> {
        let opts = options.into_engine()?;
        let engine = match path {
            Some(p) => chisel::Chisel::open(std::path::Path::new(&p), opts),
            None => chisel::Chisel::open_in_memory_with_options(opts),
        }
        .map_err(ChiselError::from)?;
        Ok(std::sync::Arc::new(Self { inner: Mutex::new(Some(engine)) }))
    }

    /// Convenience: in-memory with explicit options.
    #[uniffi::constructor]
    pub fn new_in_memory(options: Options) -> FfiResult<std::sync::Arc<Self>> {
        Self::new(None, options)
    }

    /// Flush and release the database. Idempotent-ish: a second call is Closed.
    pub fn close(&self) -> FfiResult<()> {
        let mut guard = self.inner.lock().map_err(|_| ChiselError::Poisoned)?;
        let db = guard.take().ok_or(ChiselError::Closed)?;
        db.close().map_err(Into::into)
    }

    pub fn is_poisoned(&self) -> bool {
        self.inner.lock().ok()
            .and_then(|g| g.as_ref().map(|db| db.is_poisoned()))
            .unwrap_or(true)
    }

    pub fn allocate(&self, value: Vec<u8>) -> FfiResult<chisel::Handle> {
        self.with_db(|db| db.allocate(&value))
    }
    pub fn read(&self, handle: chisel::Handle) -> FfiResult<Vec<u8>> {
        self.with_db(|db| db.read(handle))
    }
    pub fn update(&self, handle: chisel::Handle, value: Vec<u8>) -> FfiResult<()> {
        self.with_db(|db| db.update(handle, &value))
    }
    pub fn delete(&self, handle: chisel::Handle) -> FfiResult<()> {
        self.with_db(|db| db.delete(handle))
    }
    pub fn delete_many(&self, handles: Vec<chisel::Handle>) -> FfiResult<()> {
        self.with_db(|db| db.delete_many(&handles))
    }
}
```

> NOTE: `#[uniffi::constructor]` methods return `Arc<Self>` for object types; confirm the exact return-shape convention against the UniFFI interfaces doc if the build complains (some versions want `Self`, others `Arc<Self>`). The `with_db` helper is the single place the lock is taken for &mut methods — keep every mutating method routed through it.

```swift
             .lockFailed, .unsupportedFormatVersion, .unsupportedPageSize,
             .corruptPage, .invalidPageId, .poisoned, .decryptionFailed:

        }
    }
```

```swift
import Foundation

/// Synchronous, thread-confined handle to a Chisel database. NOT Sendable — the
/// caller owns threading (use your own serial queue, or prefer `ChiselStore`).
public final class ChiselDatabase {
    let native: NativeDatabase   // internal: the generated FFI object

    public init(path: URL?, options: Options = Options()) throws {
        self.native = try NativeDatabase(path: path?.path, options: options)
    }

    public var isPoisoned: Bool { native.isPoisoned() }
    public func close() throws { try native.close() }

    // Flat mirror (top-level; prefer `transaction`).
    public func allocate(_ value: Data) throws -> Handle { try native.allocate(Array(value)) }
    public func read(_ handle: Handle) throws -> Data { Data(try native.read(handle)) }
    public func update(_ handle: Handle, _ value: Data) throws { try native.update(handle, Array(value)) }
    public func delete(_ handle: Handle) throws { try native.delete(handle) }
    public func deleteMany(_ handles: [Handle]) throws { try native.deleteMany(handles) }
    public func handles() throws -> [Handle] { try native.handles() }
    public func stats() throws -> Stats { try native.stats() }
    public func counters() throws -> Counters { try native.counters() }
    public func fileSizeBytes() throws -> UInt64 { try native.fileSizeBytes() }
    public func defrag(_ options: DefragOptions = DefragOptions()) throws -> DefragStats { try native.defrag(options) }
    // (tags / client byte / roots / key mgmt / config mirror identically —
    //  forward each to the matching `native.*`. See PARITY.md for the full list.)

    /// Run `body` inside a transaction. Commits on return; rolls back and
    /// rethrows on error.
    public func transaction<R>(_ body: (Transaction) throws -> R) throws -> R {
        try native.begin()
        let txn = Transaction(native: native)
        do {
            let result = try body(txn)
            try native.commit()
            return result
        } catch {
            try? native.rollback()
            throw error
        }
    }
}

/// Operations valid only inside a `transaction { }` block. Forwards to the same
/// engine; not escapable, not Sendable.
public struct Transaction {
    let native: NativeDatabase

    public func allocate(_ value: Data) throws -> Handle { try native.allocate(Array(value)) }
    public func read(_ handle: Handle) throws -> Data { Data(try native.read(handle)) }
    public func update(_ handle: Handle, _ value: Data) throws { try native.update(handle, Array(value)) }
    public func delete(_ handle: Handle) throws { try native.delete(handle) }
    public func deleteMany(_ handles: [Handle]) throws { try native.deleteMany(handles) }
    public func allocateTagged(_ value: Data, tag: Tag) throws -> Handle { try native.allocateTagged(Array(value), tag: tag) }
    public func tag(_ handle: Handle) throws -> Tag? { try native.tag(handle: handle) }
    public func handlesWithTag(_ tag: Tag) throws -> [Handle] { try native.handlesWithTag(tag: tag) }
    public func deleteTagged(_ handle: Handle, tag: Tag) throws { try native.deleteTagged(handle: handle, tag: tag) }
    public func deleteWithTag(_ tag: Tag, max: UInt64) throws -> TagDropProgress { try native.deleteWithTag(tag: tag, max: max) }
    public func clientByte(_ handle: Handle) throws -> UInt8 { try native.clientByte(handle: handle) }
    public func setClientByte(_ handle: Handle, _ byte: UInt8) throws { try native.setClientByte(handle: handle, byte: byte) }
    public func setRootName(_ name: String, _ handle: Handle) throws { try native.setRootName(name: name, handle: handle) }
    public func getRootName(_ name: String) throws -> Handle? { try native.getRootName(name: name) }
    public func clearRootName(_ name: String) throws { try native.clearRootName(name: name) }
    public func handles() throws -> [Handle] { try native.handles() }

    /// Nested savepoint. Releases on return; rolls back to it and rethrows on error.
    public func savepoint<R>(_ name: String, _ body: (Savepoint) throws -> R) throws -> R {
        try native.savepoint(name: name)
        let sp = Savepoint(native: native, name: name)
        do {
            let result = try body(sp)
            try native.release(name: name)
            return result
        } catch {
            try? native.rollbackTo(name: name)
            throw error
        }
    }
}

/// A named savepoint scope. The same operations as `Transaction` are reachable
/// through the enclosing transaction; this type exists to scope release/rollback.
public struct Savepoint {
    let native: NativeDatabase
    public let name: String
}
```

```swift
import Foundation

/// Async, Sendable handle to a Chisel database. Serializes all engine calls on a
/// dedicated queue so blocking fsync I/O never touches the cooperative pool.
public actor ChiselStore {
    private let db: ChiselDatabase
    private let queue: DispatchQueue

    public init(path: URL?, options: Options = Options()) async throws {
        let q = DispatchQueue(label: "org.chisel.store")
        self.queue = q
        self.db = try await Self.run(on: q) { try ChiselDatabase(path: path, options: options) }
    }

    // Hop a blocking closure onto the dedicated serial queue.
    private static func run<R: Sendable>(
        on queue: DispatchQueue, _ body: @escaping @Sendable () throws -> R
    ) async throws -> R {
        try await withCheckedThrowingContinuation { cont in
            queue.async { cont.resume(with: Result { try body() }) }
        }
    }
    private func run<R: Sendable>(_ body: @escaping @Sendable () throws -> R) async throws -> R {
        try await Self.run(on: queue, body)
    }

    public func close() async throws { let db = db; try await run { try db.close() } }
    public func allocate(_ value: Data) async throws -> Handle { let db = db; return try await run { try db.allocate(value) } }
    public func read(_ handle: Handle) async throws -> Data { let db = db; return try await run { try db.read(handle) } }
    public func update(_ handle: Handle, _ value: Data) async throws { let db = db; try await run { try db.update(handle, value) } }
    public func delete(_ handle: Handle) async throws { let db = db; try await run { try db.delete(handle) } }
    public func stats() async throws -> Stats { let db = db; return try await run { try db.stats() } }
    // (full async mirror forwards each op through `run { }`; see PARITY.md.)

    /// The body is SYNCHRONOUS by design: an `await` inside would suspend while
    /// the transaction/lock is held, letting a second logical transaction
    /// interleave on the !Sync engine. A sync body makes "one transaction,
    /// start to finish" a type-level guarantee.
    public func transaction<R: Sendable>(
        _ body: @escaping @Sendable (Transaction) throws -> R
    ) async throws -> R {
        let db = db
        return try await run { try db.transaction(body) }
    }
}
```

> NOTE: `let db = db` captures the non-Sendable `ChiselDatabase` for the `@Sendable` closure; this is sound because every closure runs on the same serial `queue`, so `db` is only ever touched from one thread. If Swift 6 strict-concurrency rejects the capture, wrap `ChiselDatabase` in an `@unchecked Sendable` box documented with this same single-queue-confinement rationale.

```swift
import Foundation
import Security

public enum KeychainError: Error, Sendable {
    case itemNotFound
    case unexpectedData
    case unhandled(OSStatus)
}

extension ChiselKey {
    /// Load raw key bytes from the Keychain (a generic password item) and wrap
    /// them as `.raw`. Bytes cross the FFI immediately, where Rust zeroizes them.
    public static func keychain(service: String, account: String) throws -> ChiselKey {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: account,
            kSecReturnData as String: true,
            kSecMatchLimit as String: kSecMatchLimitOne,
        ]
        var item: CFTypeRef?
        let status = SecItemCopyMatching(query as CFDictionary, &item)
        switch status {
        case errSecSuccess:
            guard let data = item as? Data else { throw KeychainError.unexpectedData }
            return .raw(bytes: Array(data))
        case errSecItemNotFound:
            throw KeychainError.itemNotFound
        default:
            throw KeychainError.unhandled(status)
        }
    }
}
```

> NOTE: the generated `ChiselKey.raw` case label is `raw(bytes:)` per the Rust enum `Raw { bytes: Vec<u8> }`; confirm against `chisel.swift`.
